# 飞船驾驶

在服务端和客户端安装 Sable 2.0.6。用蓝图和配套零件在发射台生成飞船，再右击船身进入根指令舱的驾驶座。座位设在座椅标记上方的外部，驾驶视角随船体转动。可用 F5 切换视角，按潜行键离座。仅安装 BlockSpaceProgram 时，发射台生成静态飞船。 [装配与发射](vab.md)

| 默认按键 | 操作 |
| --- | --- |
| W / S | 绕船体 X 轴俯仰 |
| A / D | 绕船体 Y 轴偏航 |
| Z / C | 绕船体 Z 轴滚转 |
| R / V | 增加或降低节流阀 |
| X | 关闭节流阀 |
| 跳跃键（默认空格） | 进入下一级 |

起飞前，飞船满油，节流阀为零。驾驶时可在快捷栏上方查看节流百分比和剩余燃料总质量。按住 R 增推。竖直推力须超过当地的飞船重量才能离地。服务端接收驾驶员的按键，离座或输入超时会关闭节流阀和姿态输入。

把带有推力和比冲属性的零件加入蓝图。对可定向的喷管方块，朝向表示排气方向，推力反向作用。无朝向的喷管默认向下排气。指令舱内置反作用轮。分离器两侧分别供油，当前级的发动机按节流后的推力与当地比冲消耗燃料，燃尽即熄火。零件的干质量和剩余燃料分配到碰撞格，由 Sable 汇总湿质量并近似求取质心和惯量。 [零件属性数据包](part-properties.md)

## 分级与残骸

驾驶时每按一次跳跃键进入下一级。飞船先断开该级的分离接口，再启用该级发动机。装有根指令舱的船保留驾驶员和节流阀。飞船生成时可以直接使用蓝图中第一个有可用发动机的级。若这一阶段或之前安排了分离，驾驶员须按跳跃键触发该次分离。

分离后没有指令舱的船会成为残骸，继续受重力和地形碰撞影响。每个维度最多保留 32 个残骸，超出时先清理最早产生的。默认在残骸存留 300 秒游戏时间，或同维度有玩家且距最近的玩家超过 256 格时清理。可在游戏目录的 `config/blockspaceprogram-server.toml` 中调整 `[debris]` 下的 `maxCount`、`lifetimeSeconds` 和 `distance`。`maxCount = 0` 会立即清理所有残骸。时间或距离设为 0 会关闭对应的清理条件。 [两级火箭示例](vab.md#两级火箭示例)

## 着陆

用包含避雷针的结构烘焙着陆腿。每条腿的接触点在该零件局部底面的中心，缓冲行程为原尺寸 0.75 格，随零件缩放。把腿的底面朝向地面并伸到船身以下，让几条腿的接触点围住质心。阶梯地形需要留出足够的船底间隙。

脚下探测到地形的碰撞面时，弹簧力随压缩量增加，阻尼减缓接近并抑制反弹。脚底的实体碰撞体承受剩余重量。方块地形和 Create 移动机构都由 Sable 解算刚体碰撞。停稳后的刚体由 Sable 自动休眠，发动机、反作用轮或外部碰撞可将它唤醒。

碰撞点沿接触面法线的相对速度超过该零件的耐冲击速度时，零件受损。受损的发动机、着陆腿和反作用轮停止工作，受损的燃料舱失去剩余燃料。损坏状态随船保存，驾驶界面显示受损零件数量。受损零件仍保留船体连接和实体碰撞。

## 天体参数

在数据包的 `data/<维度命名空间>/ship_flight/<维度路径>.json` 中配置飞船重力和大气。以下是内置的主世界参数。每格为一米，海拔从 `sea_level` 起算。海平面以上的重力按距天体中心的距离平方衰减。大气密度按 `scale_height` 衰减，并在 `atmosphere_top` 降到零。将海平面密度设为零可配置真空。

```json
{
  "sea_level": 63,
  "radius": 60000,
  "surface_gravity": 9.8,
  "sea_level_density": 1.225,
  "atmosphere_top": 4000,
  "scale_height": 1000,
  "orbit_handoff": {
    "ascent_altitude": 6000,
    "descent_altitude": 5000
  }
}
```

距离单位为 m，`surface_gravity` 的单位为 m/s²，`sea_level_density` 的单位为 kg/m³。飞船用零件的阻力系数、当前迎风投影面积和相对空气的速度计算阻力。没有专用天体参数的维度使用 Sable 的维度重力和气压，Sable 的求解器阻尼也适用于飞船。修改数据包后执行 `/reload`。 [母星参数设计 #4](https://github.com/jxt159753/BlockSpaceProgram/issues/4)

## 无人飞船与轨道交接

`orbit_handoff` 为可选配置，天体 ID 对应维度 ID。上升和下降阈值均为质心海拔。上升阈值须高于下降阈值，下降阈值须高于大气顶，并给整艘飞船留出高于建筑上限的净空。卫星 `blockspaceprogram:moon` 的默认上升和下降阈值分别为 1,500 m 和 1,000 m，待同名维度加载后生效。 [天体轨道参数](orbit.md#m3-天体) · [卫星维度 #17](https://github.com/jxt159753/BlockSpaceProgram/issues/17)

无人飞船从投影范围内上升越过阈值后进入轨道层。在下降阈值处重建 Sable 刚体，并恢复零件图、燃料、分级、损坏、非玩家座位乘客、姿态和角速度。轨道交接检查以天体为中心的比轨道能量。无法拟合成开普勒根数的精确径向轨迹会保留原实体。 [星球尺度 #4](https://github.com/jxt159753/BlockSpaceProgram/issues/4)

## 轨道局部物理区

载有玩家的飞船上升越过阈值后进入虚空维度 `blockspaceprogram:orbital_space`。驾驶员随船转移，继续使用发射后的驾驶按键。回落越过下降阈值时，该船及其乘员回到行星维度。轨道区的其他成员可以继续飞行。服务器共用一个物理区。 [局部物理区 #34](https://github.com/jxt159753/BlockSpaceProgram/issues/34)

离座会继承船体在座位处的速度。舱外玩家重力为零，可双击跳跃键切换飞行，用常规移动、跳跃和潜行键接近另一艘飞船。在轨下线会保存所乘飞船或自身的轨道状态。最后一名玩家离开后，飞船转回轨道数据，上线时按当前轨道时刻重建。

每 5 游戏刻检查一次接近距离和相对速度。无人船距离任一成员小于 1,000 m 且相对速度不超过 40 m/s 时并入。无人船与所有其他成员的距离都超过 1,200 m 时转回轨道数据。可在 `config/blockspaceprogram-server.toml` 的 `[orbitalPhysics]` 调整 `entryDistance`、`exitDistance` 和 `maxEntrySpeed`。有效退出距离至少比进入距离多 1 m。远处飞船在视野内显示距离，4 km 内额外显示简化轮廓。 [轨道空间天空](sky.md#轨道空间)

轨道层的机动节点用于纯轨道数据。飞船重建为刚体后由驾驶操作点火，原来排队的机动节点随旧轨道记录移除。

### 调试命令

Sable 服务端的管理员可执行以下命令。输入飞船参数时，Tab 补全会列出当前维度已加载的飞船和在轨飞船的 UUID。位置是质心的维度坐标，速度单位为 m/s。可用 `/execute in <维度> run ...` 指定维度。

```text
/bsp_ship position <飞船UUID> <x> <y> <z> <vx> <vy> <vz>
/bsp_ship orbit <飞船UUID> <天体ID> <半通径m> <偏心率> <倾角> <升交点经度> <近地点幅角> <平近点角>
```

轨道根数的角度用度，历元取当前轨道时刻。母星 10 km 圆轨道可用 `minecraft:overworld 70000 0 0 0 0 0`。测试亚轨道往返时，把母星上的飞船放到阈值下方，例如 `0 6060 0 0 30 0`。飞船将先越过 Y 6063，再沿弹道回落，在 Y 5063 附近恢复为实体。
