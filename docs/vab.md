# 装配大楼与发射台

装配台界面和零件提示随 Minecraft 的语言设置显示，支持 English (US)、简体中文和繁體中文（台灣）。

用工作台、铁块和纸合成装配台。用铁块、红石和平滑石头合成发射台。纸和蓝色染料可合成空白飞船蓝图。

1. 右击装配台。在下方背包格选中烘焙好的指令舱，再点击 3D 区域放置它作为根零件。
2. 选中下一个零件。切换堆叠或表面模式，点击方向按钮选择接入面，再点击船上的目标接口或表面。绿色线框预览可放置位置，蓝色轮廓标出可用的目标堆叠接口和来件上已烘焙的接口。预览左上角显示来件接入接口的实际尺寸。可按 90° 旋转、选用 2 重或 4 重对称。按住右键拖动可转视角，滚轮缩放，Shift 点击可移除零件及失去连接的部分。
3. 点分级区的 `+` 增加一级，拖动分离、点火和武装伞动作到各级。每级按这个顺序执行。已点火的发动机在完好且有供能时持续可用。把芯级和侧挂助推器排在同一级点火，分离助推器后芯级仍可继续工作。新放置的发动机和降落伞默认分配到第 1 级，混合零件可以把两个动作分配到不同级。
4. 选中空白蓝图并点击保存。装配台可载入背包中的纯零件蓝图。

装配台右上角显示零件数和上限，超出时标红。保存时检查装配台等级。发射时同时检查装配台零件数上限和发射台满油质量上限，超限时保留材料。 [设施等级与上限](facility.md)

右侧按满油、满电和真空比冲估算各级 Δv、起始推重比和燃烧时间，并显示本级开始时的合推力方向。推重比使用标准重力，并计入本级开始时能工作的发动机。燃料在不可分离连接形成的组内共享。全船共享电量，每个电池按自己的剩余电量比例供电。分离时，各部分带走自己的电量。

估算按燃料组或电量耗尽的时刻分段，停止相应发动机后重新计算推力和消耗。下一级即将分离的燃料组若在本级开始时供油，本级在这些组的发动机全部停机时结束。其余情况下，本级一直估算到所有发动机失去供能。推力按船体坐标相加，合推力为零时仍计入消耗和燃烧时间，Δv 为零。

有武装伞动作的级还显示全开下降速度。估算取执行本级分离后留在根指令舱一侧的飞船，燃料按满载计，伞按全部全开计。使用装配台所在维度的海平面大气密度和重力。密度为 0 时显示「无大气」。若伞全部随分离件离开，显示「根舱侧无伞」。世界内组装使用同样的分级动作。 [降落伞](flight.md#降落伞)

## 用蓝图组装飞船

配齐蓝图所需的烘焙零件和船体方块。手持蓝图右击有足够净空的发射台。发射台依次从主背包、副手和相邻容器扣料。上下前后左右六个方块都可供料，取料面是容器朝向发射台的一侧。发射台会跳过玩家无权交互的容器。缺材料时会提示第一种缺少的物品和数量。生成飞船后扣料，蓝图可继续使用。

带船体的蓝图需要安装 Sable。发射前逐格检查船体占用的位置。双层台阶扣 2 个台阶，3 根蜡烛扣 3 个蜡烛。门和高草丛各按下半格扣 1 件。设施等级限制中的零件数只计烘焙零件，满油质量包含船体。安装 Sable 后可右击船身登船。 [飞船驾驶](flight.md)

## 世界内拼接与就地组装

1. 手持烘焙零件右击方块面，在 1/4 格网格上放置第一个零件。再手持来件对准已放置零件的接口或表面。瞄准堆叠接口时优先选取尺寸匹配、朝向相对的来件接口。
2. 按 `G` 切换自动匹配和强制表面附着，按 `H` 切换来件的连接面，按 `B` 绕目标法线旋转 90°。贴到零件表面时，按 `N` 切换围绕目标零件的 1 重、2 重和 4 重对称。每个位置的线框均可放置时右击接合。生存模式从背包和副手扣除对应数量的相同零件。
3. 右击指令舱查看零件数、满油总质量、对应上限和每级 Δv。分级区与装配台相同，可以增加级数并拖动点火和分离动作。空手右击可收回普通零件，空手潜行右击可收回指令舱。收回中间零件后，断开的结构留在原处，各自形成独立的组。
4. 点击「组装成飞船」，或者用铁锭、铜锭和红石合成飞船组装器，再右击组内任一零件。每组须有指令舱，且所有成员都须已加载并可编辑。就地组装应用与发射台相同的零件数和满油质量上限。组装只使用这组已有的零件，飞船保持原位置和朝向，背包中的零件数量不变。多人同时组装同一组零件时，只有一个请求会生成飞船。
5. 手持空白蓝图右击组装好的飞船的指令舱，将零件设计、分级和船体保存到蓝图。蓝图分别显示零件数和船体方块数。装配台只载入纯零件蓝图。修改船体时，在世界中搭好结构并重新组装，再保存一份蓝图。

### 用普通方块搭船体

安装 Sable 后，用普通方块搭出一片面相连的船体。用发射台或脚手架隔开船体和地面。服务器可用 `#blockspaceprogram:hull_boundary` 添加其他边界方块。边界方块留在原地。

将至少一个烘焙指令舱贴到船体上。零件的碰撞盒须完整覆盖所贴船体方块的一面。与船体相连的零件组会一同组装，已有分级编号继续使用。手持飞船组装器右击船体方块。右击零件仍只组装其零件组。

每次组装收集一片船体。`blockspaceprogram-server.toml` 的 `[hull]` 中，`maxBlocks` 默认设为 8192。船体接上地形并超过上限、含有箱子等带方块实体的方块，或与零件碰撞格同格时，组装会失败并保留原结构。流体、不可破坏的方块和没有方块物品的方块也会阻止组装。

组装后可以走进船体。空手潜行右击指令舱可查看满油质量和分级性能。飞行中可以开关门和拨动拉杆。重建刚体时，船体恢复为组装时的方块状态。飞行中不能放置或破坏船体方块。带船体的飞船可以对接。 [对接与解除对接](flight.md#对接与解除对接)

## 烘焙连接接口

堆叠接口的正面是青色方环，分离接口是红色双箭头，对接接口是金色圆环，附着面是紫色四格面板。标示面朝向放置时点击的方块面，例如点击模块底面可安装朝下的接口。把朝向一致的堆叠、分离或对接接口铺成实心正方形或一格宽的正方形边框，保持标示面朝外且正前方无遮挡。

环形接口外边至少 3 格，每个边框位置都要放接口方块，中间全部留空。用 12 块接口方块围出 4×4 的边框，可在后方接一段内孔 2×2 的方管。环形和实心接口均按外边长及中心对齐，同尺寸可以匹配。Sable 按烘焙方块的占用生成碰撞格。要让通道完全打开，把通道边缘和飞船整格网格对齐。 [简化碰撞与调试显示](part-baking.md#简化碰撞与调试显示)

选中来件的分离接口，可堆叠接合，也可在表面模式下直接贴到芯级侧面。两种方式均生成可分离连接。装配台和世界内组装的各个对称副本各有一条连接，可在分级区分别指定分离级。普通表面附着可使用来件包围盒的一面，或用附着面方块标出的矩形。来件附着面必须完全落在目标碰撞盒表面内。

接口、模型和碰撞盒共用烘焙结构最小角和比例。堆叠按实际尺寸匹配，例如半尺寸的 4×4 接口可接原尺寸的 2×2 接口。接口边缘落在 1/4 格网格上，奇数个 1/4 格宽的接口中心处在两个网格点之间。默认允许全部可烘焙的接口尺寸。可在数据包的 `data/blockspaceprogram/data_maps/block/connector_sizes.json` 中为 `blockspaceprogram:stack_interface` 配置尺寸档，单位为 1/4 格，执行 `/reload` 后应用于后续接入和烘焙。 [旧比例迁移规则](part-baking.md#缩放预览和放置)

```json
{
  "values": {
    "blockspaceprogram:stack_interface": [1, 2, 4, 8, 12, 16]
  }
}
```

## 制作与抛离整流罩

1. 在工作台横排 3 枚铁锭，合成 6 块整流罩板。原尺寸下每块质量为 10 kg，迎风面的阻力系数为 0.30。
2. 用整流罩板搭两片相同的半壳，分别在烘焙台烘焙。每片在靠芯级的一侧放一个分离接口，红色标示面朝向芯级。让半壳的包围盒与已有零件错开，给抛离路线留出净空。
3. 在装配台把载荷接到主船上。选中半壳，切到「表面」模式并选中分离接口。开启 2 重对称，点击芯级侧面。在预览中确认两片都能放置，再接合。
4. 把两条半壳分离动作拖到同一个分级，例如第 2 级，再保存蓝图。安装 Sable 时，发射后按跳跃键进入抛罩级。两片半壳向两侧分离，载荷随主船继续飞行。

可用 1 格宽、南北 3 格长、3 格高的芯级验证轴向遮挡。用一对堆叠接口把 3×3 载荷接在芯级正下方。每片半壳宽 1 格，南北长 3 格。从下往上，第一层中央放 1 块整流罩板，第二层中央放朝西的分离接口、南北各放 1 块板，第三层铺满 3 块板。用 2 重对称接到芯级东侧的中心。沿船首方向飞行时，半壳的顶层挡住露在芯级两侧的载荷。迎风方向改变时，遮挡结果随各轴投影变化。 [飞行与气动阻力](flight.md)

只装本模组的专用服也可以合成、烘焙整流罩板，并用只含烘焙零件的蓝图在发射台生成带罩的静态飞船。

## 制作与装配隔热罩

1. 在工作台上横排 3 块黑曜石，在下一行横排 3 枚铁锭，合成 6 块隔热罩。原尺寸下每块质量为 350 kg，耐热温度为 1,600 K。
2. 将隔热罩铺成能覆盖返回舱底面的零件，在烘焙台烘焙，再接到舱底。零件采用组成方块中最低的非零耐热温度。需要抛离时，把分离接口做在罩后的独立零件上，再在装配台设置分离级。
3. 返回时让隔热罩所在的一面朝向飞船的空速方向。罩边之外和侧向迎风的节点仍会受热。隔热罩无需补充材料，可以随返回舱保留。 [气动遮挡与再入加热](flight.md#再入加热)

只装本模组的专用服也能合成、烘焙和装配隔热罩，并通过发射台生成带罩的静态飞船。

## 两级火箭示例

按零件属性数据包的说明，把橡木木板加入 `command_seats`，把切制铜块加入 `engine_nozzles`。给切制铜块配置质量 25 kg、推力 12,000 N、真空比冲 300 s、海平面比冲 270 s。[零件属性数据包](part-properties.md)

分别在烘焙台上按从下往上的顺序搭建并烘焙这四个模块。接口方块的箭头表示外侧面朝向。

| 零件 | 从下往上的方块 |
| --- | --- |
| 指令舱 | 堆叠接口 ↓、橡木木板 |
| 上级发动机舱 | 堆叠接口 ↓、切制铜块、炼药锅、堆叠接口 ↑ |
| 分离器 | 分离接口 ↓、堆叠接口 ↑ |
| 下级发动机舱 | 堆叠接口 ↓、切制铜块、两个炼药锅、堆叠接口 ↑ |

从指令舱开始，在 3D 界面把后三件依次接到上一件的正下方，每次选来件朝上的接口。让第 1 级点燃下级发动机，将分离下级和点燃上级安排到第 2 级。按这组数值，第 1 级 Δv 为 1339.0 m/s，第 2 级为 1783.2 m/s。保存蓝图后，可准备两个净空的发射台验证。同一套四个零件只能在第一座台生成一艘。补齐第二套后，用同一蓝图在另一座台生成第二艘。

在世界中验证同一设计时，把指令舱放到高处临时方块的侧面，在舱下预留至少 11 格净空。瞄准每个下向接口，依次接入上级发动机舱、分离器和下级发动机舱。按同样方式编排分级，比较指令舱显示的 Δv。收回分离器后，指令舱仍可与上级发动机舱组装，下级发动机舱留在原处。
