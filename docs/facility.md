# 设施等级与上限

设施等级从 1 开始。烘焙台限制单个零件的方块数，装配台限制每艘飞船的零件数，发射台限制满油质量。满油质量是所有零件的干质量与燃料容量之和，单位为 kg。

- 烘焙前检查方块数。超限时保留原结构和铜锭。 [烘焙与拆解零件](part-baking.md)
- 保存蓝图时检查零件数。装配台界面显示零件数和上限，超出时标红。
- 发射和就地组装时同时检查零件数和满油质量。超限时保留材料和已拼接的结构。指令舱界面显示两项上限。拼接阶段可以继续摆放和调整零件。 [装配与发射](vab.md)

## 等级归属

等级保存在主世界的数据目录，同一服务器的所有维度共用。安装 FTB Teams 后，组队玩家共用队伍等级。加入队伍时使用队伍等级，退出后恢复自己的个人等级。队伍和个人记录各自保留。

未安装 FTB Teams 或玩家未组队时，使用玩家 UUID 对应的个人等级。因此加装 FTB Teams 后，未组队的玩家仍可使用原来的个人等级。Create 机械手等假玩家使用 `defaultTier`。

## 服务器配置

在 `blockspaceprogram-server.toml` 的 `[facility]` 一节设置等级。列表第几项对应第几级，长度决定可设置的等级数。值为 `0` 时，该级设施没有额外上限。现有的单件 9×9×9 烘焙范围和单船 36 件的设计上限仍然适用。

| 配置项 | 默认值 | 用途 |
| --- | --- | --- |
| `bakingTableMaxBlocks` | `[729]` | 单个零件的方块数 |
| `assemblyTableMaxParts` | `[0]` | 每艘飞船的零件数 |
| `launchPadMaxMass` | `[0]` | 每艘飞船的满油质量，单位为 kg |
| `defaultTier` | `1` | 某项设施没有存档记录时使用的等级 |

存档等级或 `defaultTier` 超出某个列表的长度时，按列表最后一级查上限。缩短列表后，存档中的原等级仍会保留。服务器会在打开装配台或指令舱界面时发送当前上限。等级变化后可以重新打开界面查看。

## 命令和任务奖励

| 命令 | 权限 | 用途 |
| --- | --- | --- |
| `/bsp_facility get` | 所有玩家 | 查看自己当前使用的三种设施等级和上限 |
| `/bsp_facility get <玩家>` | 2 | 查看指定在线玩家所属队伍或个人的等级和上限 |
| `/bsp_facility set <玩家> <设施> <等级>` | 2 | 设置指定在线玩家所属的队伍或个人等级 |

设施 ID 为 `baking_table`、`assembly_table` 和 `launch_pad`。重复设为同一等级会成功。

例如，将 `launchPadMaxMass` 配为 `[100, 0]`，使 1 级的满油质量上限为 100 kg，2 级解除质量限制。在 FTB Quests 的命令奖励中填入 `/bsp_facility set {p} launch_pad 2`，把命令权限设为 2。`{p}` 会替换成领奖玩家名，领奖时设置该玩家所属归属的发射台等级。
