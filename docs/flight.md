# 飞船驾驶

在服务端和客户端安装 Sable 2.0.6。用蓝图和配套零件在发射台生成飞船，再右击船身进入根指令舱的驾驶座。座位设在座椅标记上方的外部，第一人称视角随船体转动。[可用 F5 切换视角](#飞行视角)，按潜行键离座。仅安装 BlockSpaceProgram 时，发射台生成静态飞船。 [装配与发射](vab.md)

| 默认按键 | 操作 |
| --- | --- |
| W / S | 绕船体 X 轴俯仰 |
| A / D | 绕船体 Y 轴偏航 |
| Z / C | 绕船体 Z 轴滚转 |
| R / V | 增加或降低节流阀 |
| X | 关闭节流阀并取消自动节流 |
| J | 切换姿态模式 |
| K | 切换节流模式并记录当前值 |
| 跳跃键（默认空格） | 进入下一级 |

起飞前，飞船满油，节流阀为零。驾驶时可在快捷栏上方查看姿态和节流模式、节流百分比和剩余燃料总质量。按住 R 增推。竖直推力须超过当地的飞船重量才能离地。离座或驾驶输入超时后，手动节流归零，自动模式继续使用当前设定值。

把带有推力和比冲属性的零件加入蓝图。对可定向的喷管方块，朝向表示排气方向，推力反向作用。无朝向的喷管默认向下排气。指令舱内置反作用轮。分离器两侧分别供油，已点火的发动机按节流后的推力与当地比冲消耗燃料。合推力是各发动机推力矢量和的大小。方向相反的发动机可以相互抵消，仍各自耗油。零件的干质量和剩余燃料分配到碰撞格，由 Sable 汇总湿质量并近似求取质心和惯量。 [零件属性数据包](part-properties.md)

## 飞行视角

驾驶时按 F5，依次切换第一人称、第三人称背后、锁定载具视角、解锁载具视角和第三人称正面，再回到第一人称。两种载具视角都以飞船为中心，移动鼠标可以绕船观察。锁定视角随船体转动。解锁视角以世界的竖直方向为上，此时可以观察船体相对地平线的俯仰和滚转。

在载具视角下滚动滚轮可拉近或拉远。无遮挡时，默认距离为 `1.75 × max(4, 半对角线)` 格，最近距离为 `max(4, 半对角线)` 格。半对角线取 Sable 子层级地块包围盒的对角线长度的一半。地形遮挡时，Sable 会把相机拉到遮挡物前。可在 Sable 客户端配置中调整 `sub_level_zoom_sensitivity`，默认值为 0.2。

可在按键设置的 BlockSpaceProgram 分类里绑定「切换飞船视角」。驾驶时按下可在第一人称与上次使用的载具视角间切换。首次使用时进入锁定视角。此键默认未绑定。

进入轨道、下降到母星或卫星、分级分离、对接和解除对接时，飞船恢复原来的载具视角和缩放量。交接期间按 F5 或「切换飞船视角」可取消恢复。在载具视角中按潜行键离座会回到第一人称，再次上座时仍为第一人称。

## 内置飞控

按 J 依次切换手动、消除旋转、保持航向、顺向和逆向。保持航向记录切换时的姿态。顺向和逆向将船体 +Y 轴分别对准速度方向和反方向。速度低于 0.1 m/s 时保持最近一次目标姿态。

按 K 依次切换垂直速度、推重比和手动。进入自动节流模式时以切换当时的读数为目标。切回手动时保留当前节流百分比。按 X 可以立即关停。姿态键和 R / V 在按住时接管各自的控制轴，松开即恢复自动控制。

安装 Sable 即可使用内置模式。安装 CC:Tweaked 后，可通过地面飞控终端设置具体目标。 [外设指令和无人起飞脚本](flight-computercraft.md)

## 分级与残骸

驾驶时每按一次跳跃键进入下一级。飞船先断开该级的分离接口，再启用该级发动机。仍在船上、完好且有油的已点火发动机在后续级继续工作。装有根指令舱的船保留驾驶员和节流阀。飞船生成时可以直接使用蓝图中第一个有可用发动机的级。若这一阶段或之前安排了分离，驾驶员须按跳跃键触发该次分离。

分离后没有指令舱的船会成为残骸，继续受重力和地形碰撞影响。每个维度最多保留 32 个残骸，超出时先清理最早产生的。默认在残骸存留 300 秒游戏时间，或同维度有玩家且距最近的玩家超过 256 格时清理。可在游戏目录的 `config/blockspaceprogram-server.toml` 中调整 `[debris]` 下的 `maxCount`、`lifetimeSeconds` 和 `distance`。`maxCount = 0` 会立即清理所有残骸。时间或距离设为 0 会关闭对应的清理条件。 [两级火箭示例](vab.md#两级火箭示例)

## 对接与解除对接

在零件的外侧烘焙实心或环形的正方形对接口。两艘飞船的空闲对接口朝向彼此、缩放后的外边长相同，并进入捕获范围时会自动对接。对接适用于近地飞行与轨道局部物理区。飞船对齐到最近的 90° 转角，合并后的分级最多 72 级。 [烘焙连接接口](vab.md#烘焙连接接口)

带船体的舱段对齐时，上方必须与合并船一致，船体只能绕竖直轴转 90° 的倍数。旋转也会调整楼梯等方块的朝向。把两艘船的对接口按各自的船体方块网格对齐，使合并后的船体方块落在整格。船体方块之间或船体方块与零件碰撞格同格时，接口不会吸附。合并船最多有 27 个船体节点和 36 个零件，共 63 个节点。

要在对接后走进另一艘船，可在两侧船体各留一个 2×2 的洞，再装上外框 4×4、边框宽 1 格的环形对接口。接口和后方方管的 2×2 内孔都要留空，通道边缘对齐船体的整格网格。Sable 按烘焙方块占用生成碰撞格，错开整格时，格内占用合成的包围盒可能挡住通道。 [简化碰撞与调试显示](part-baking.md#简化碰撞与调试显示)

默认捕获距离为 0.25 m，允许偏离对齐姿态 8°，接口中心的相对速度最多 0.5 m/s。可在 `config/blockspaceprogram-server.toml` 的 `[docking]` 下调整 `captureDistance`、`captureAngle` 和 `captureSpeed`。

对接后主船的分级排在前面。只有一艘船正被驾驶时，该船为主船。两艘都有人驾驶或都无人驾驶时，湿质量较大的一艘为主船。驾驶员留在各自的指令舱，主船的驾驶员继续操控整船。叠放的指令舱遮挡原座位时，座位可移到舱外侧。驾驶座空出时，下一位乘员接手。

驾驶员执行 `/bsp_dock` 查看对接连接编号，再用 `/bsp_dock release <编号>` 解除对应连接。若两端仍可经其他连接相通，飞船维持一体。若船体分开，双方恢复各自的名称、根指令舱、分级顺序和轨道层 ID，并获得分离冲量。解除后，驾驶员一侧的接口暂停捕获。执行 `/bsp_dock arm` 可重新启用该船上暂停的接口。

对接和解除对接时，站在船体里的乘员会留在原舱段的相同位置。

管理员也可用 `/bsp_dock ship <飞船UUID>` 操作当前维度中的飞船，并在 UUID 后附加 `release <编号>` 或 `arm`。

## 着陆

用包含避雷针的结构烘焙着陆腿。每条腿的接触点在该零件局部底面的中心，缓冲行程为原尺寸 0.75 格，随零件缩放。把腿的底面朝向地面并伸到船身以下，让几条腿的接触点围住质心。阶梯地形需要留出足够的船底间隙。

脚下探测到地形的碰撞面时，弹簧力随压缩量增加，阻尼减缓接近并抑制反弹。脚底的实体碰撞体承受剩余重量。方块地形和 Create 移动机构都由 Sable 解算刚体碰撞。停稳后的刚体由 Sable 自动休眠，发动机、反作用轮或外部碰撞可将它唤醒。

碰撞点沿接触面法线的相对速度超过该零件的耐冲击速度时，零件受损。受损的发动机、着陆腿和反作用轮停止工作，受损的燃料舱失去剩余燃料。损坏状态随船保存，驾驶界面显示受损零件数量。受损零件仍保留船体连接和实体碰撞。

## 天体参数

在数据包的 `data/<维度命名空间>/ship_flight/<维度路径>.json` 中配置飞船重力和大气。以下是内置的主世界参数。每格为一米，海拔从 `sea_level` 起算。海平面以上的重力按距天体中心的距离平方衰减。大气密度按 `scale_height` 衰减，并在 `atmosphere_top` 降到零。将海平面密度设为零可配置真空。

```json
{
  "sea_level": 63,
  "radius": 60000,
  "surface_gravity": 9.8,
  "sea_level_density": 1.225,
  "atmosphere_top": 4000,
  "scale_height": 1000,
  "orbit_handoff": {
    "ascent_altitude": 6000,
    "descent_altitude": 5000
  }
}
```

距离单位为 m，`surface_gravity` 的单位为 m/s²，`sea_level_density` 的单位为 kg/m³。飞船用零件的阻力系数、当前迎风投影面积和相对空气的速度计算阻力。没有专用天体参数的维度使用 Sable 的维度重力和气压，Sable 的求解器阻尼也适用于飞船。修改数据包后执行 `/reload`。 [母星参数设计 #4](https://github.com/jxt159753/BlockSpaceProgram/issues/4)

玩家、生物和掉落物的重力乘以当前维度的 `surface_gravity / 9.8`。母星默认沿用原版重力。没有 `ship_flight` 参数的维度保留原有重力。修改参数并执行 `/reload` 后，已加载的实体也会采用新重力。

## 卫星维度

本模组自带 `blockspaceprogram:moon`。零海拔为 Y 63，表面重力为 1.6 m/s²，约为母星的 16.3%。默认地表在 Y 63 附近，由原版石头和安山岩生成。卫星没有降水和天然液体，也没有自然生成的生物。建筑范围为 Y -64 至 Y 319，从建筑上限 Y 320 到下降交接高度 Y 1,063 留出 743 格净空。可执行 `/execute in blockspaceprogram:moon run tp @s 0 200 0` 进入卫星。 [卫星维度 #17](https://github.com/jxt159753/BlockSpaceProgram/issues/17)

### 覆盖卫星地形

创建下列数据包，在新建存档时启用。专用服首次启动前，将数据包目录放进 `world/datapacks/`。在数据包根目录写入 `pack.mcmeta`。

```json
{
  "pack": {
    "pack_format": 48,
    "description": "Flat moon terrain"
  }
}
```

在同一数据包内创建 `data/blockspaceprogram/dimension/moon.json`。以下配置保留卫星维度类型和生物群系，在 Y 63 生成平坦的安山岩表面。重力和轨道交接仍由 `ship_flight/moon.json` 提供。

```json
{
  "type": "blockspaceprogram:moon",
  "generator": {
    "type": "minecraft:flat",
    "settings": {
      "biome": "blockspaceprogram:moon",
      "layers": [
        { "height": 1, "block": "minecraft:bedrock" },
        { "height": 126, "block": "minecraft:stone" },
        { "height": 1, "block": "minecraft:andesite" }
      ],
      "structure_overrides": []
    }
  }
}
```

## 无人飞船与轨道交接

`orbit_handoff` 为可选配置，天体 ID 对应维度 ID。上升和下降阈值均为质心海拔。上升阈值须高于下降阈值，下降阈值须高于大气顶，并给整艘飞船留出高于建筑上限的净空。卫星 `blockspaceprogram:moon` 的默认上升和下降阈值分别为 1,500 m 和 1,000 m。 [天体轨道参数](orbit.md#m3-天体)

无人飞船从投影范围内上升越过阈值后进入轨道层。在下降阈值处重建 Sable 刚体，并恢复零件图、燃料、分级、损坏、非玩家座位乘客、姿态和角速度。轨道交接检查以天体为中心的比轨道能量。无法拟合成开普勒根数的精确径向轨迹会保留原实体。 [星球尺度 #4](https://github.com/jxt159753/BlockSpaceProgram/issues/4)

## 轨道局部物理区

载有玩家的飞船上升越过阈值后进入虚空维度 `blockspaceprogram:orbital_space`。驾驶员随船转移，继续使用发射后的驾驶按键。回落越过下降阈值时，该船及其乘员回到行星维度。轨道区的其他成员可以继续飞行。单人存档同时最多有一个物理区。 [局部物理区 #34](https://github.com/jxt159753/BlockSpaceProgram/issues/34)

联机时，服务端计算飞船位置、姿态和碰撞。客户端用 Sable 的姿态快照插值显示实船。在轨玩家每 5 游戏刻收到 4 km 内的物理区飞船接触点。客户端按轨道时钟和接触点速度补偿两次更新之间的移动。 [多人同步 #23](https://github.com/jxt159753/BlockSpaceProgram/issues/23)

离座会继承船体在座位处的速度。舱外玩家重力为零，可双击跳跃键切换飞行，用常规移动、跳跃和潜行键接近另一艘飞船。在轨下线会保存所乘飞船或自身的轨道状态。一个物理区的最后一名玩家离开后，该区飞船转回轨道数据，上线时按当前轨道时刻重建。

多人服的玩家可以在各自的物理区内飞行，所有物理区共用服务器轨道时钟。两区有成员间距小于 1,000 m，且近距离成员的相对速度均不超过 40 m/s 时，两区合并。载有玩家的飞船或舱外玩家距离同区其他所有成员超过 1,200 m 时，会进入自己的物理区。飞船和乘员会在轨道空间维度内一起移动。反向高速交会时仍可通过 HUD 查看对方。 [物理区合并与拆分 #50](https://github.com/jxt159753/BlockSpaceProgram/issues/50)

每 5 游戏刻预测物理区之间的最近点，并为可能接近的区核对实际距离和相对速度。无人船距离任一成员小于 1,000 m 且相对速度不超过 40 m/s 时并入。无人船与所有其他成员的距离都超过 1,200 m 时转回轨道数据。可在 `config/blockspaceprogram-server.toml` 的 `[orbitalPhysics]` 调整物理区合并、拆分和无人船进出所用的 `entryDistance`、`exitDistance` 和 `maxEntrySpeed`。有效退出距离至少比进入距离多 1 m。远距目标在视野内显示距离，4 km 内额外显示简化轮廓。4 km 内的目标转到画面外时，屏幕边缘显示其方向和距离。 [轨道空间天空](sky.md#轨道空间)

轨道层的机动节点用于纯轨道数据。轨道地图按正在供油的各组推力方向计算合推力。合推力抵消为 0 N 时，地图禁用执行，服务端拒绝新机动并在已排队机动到时取消。飞船重建为刚体后由驾驶操作点火，原来排队的机动节点随旧轨道记录移除。

## 卫星降落与返航

从卫星低轨降落时，先选定开始减速的时机。按 **J** 切到逆向姿态，待飞船对准绕月速度的反方向后用 **R** 增加节流。驾驶界面显示当前海拔和近点海拔。近点降到 **1,000 m** 以下后，可按 **X** 关停发动机，让飞船下降到交接高度。减速的时机和幅度决定飞船在月面上空的交接位置。

服务端在预测交接前最多 10 个轨道秒申请目标区块。区块就绪后，飞船在投影位置上空恢复刚体，继承转换到当地坐标的速度。驾驶员留在座位上。如果抵达时区块仍在生成，飞船会等待区块就绪，并沿用越过阈值时的位置和线速度。

月球处于真空环境。回到卫星维度后，用推力减小横向和下落速度，再将着陆腿对准地面，调节节流平稳接地。再次起飞时保留一定横向速度，质心上升越过 **1,500 m** 后返回轨道局部物理区。要留在轨道上，可在高处顺向点火，把近点抬到 **1,000 m** 以上。上述高度为内置卫星的默认值。 [再入与着陆点选择 #18](https://github.com/jxt159753/BlockSpaceProgram/issues/18)

## 调试命令

Sable 服务端的管理员可执行以下命令。输入飞船参数时，Tab 补全会列出当前维度已加载的飞船和在轨飞船的 UUID。位置是质心的维度坐标，速度单位为 m/s。可用 `/execute in <维度> run ...` 指定维度。

```text
/bsp_ship position <飞船UUID> <x> <y> <z> <vx> <vy> <vz>
/bsp_ship orbit <飞船UUID> <天体ID> <半通径m> <偏心率> <倾角> <升交点经度> <近地点幅角> <平近点角>
```

轨道根数的角度用度，历元取当前轨道时刻。母星 10 km 圆轨道可用 `minecraft:overworld 70000 0 0 0 0 0`。测试亚轨道往返时，把母星上的飞船放到阈值下方，例如 `0 6060 0 0 30 0`。飞船将先越过 Y 6063，再沿弹道回落，在 Y 5063 附近恢复为实体。
