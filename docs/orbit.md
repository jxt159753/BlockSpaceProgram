# 轨道数据

所有维度共用主世界存档中的天体系统、轨道时钟和飞船记录，文件为 `data/blockspaceprogram_orbits.dat`。常速下每游戏刻推进 0.05 轨道秒，20 TPS 时与现实时间同速。天体与飞船用同一时刻求值，位置单位为米，速度单位为米每秒。惯性坐标系使用 XY 参考平面和 +Z 北向，角度用弧度。 [时间方案 #2](https://github.com/jxt159753/BlockSpaceProgram/issues/2)

## 天体与新存档

| 标识 | 半径（m） | 引力参数 μ（m³/s²） | 父天体 |
| --- | ---: | ---: | --- |
| `minecraft:overworld` | 60,000 | 3.528 × 10¹⁰ | 无 |
| `blockspaceprogram:moon` | 12,000 | 2.304 × 10⁸ | `minecraft:overworld` |

新存档首次启动时生成卫星轨道。间距档位确定半长轴的抽样范围。下表的霍曼时间以母星海拔 10 km 的圆轨道为起点，按卫星半长轴对应的圆轨道估算，取整到分钟。 [星球尺度 #4](https://github.com/jxt159753/BlockSpaceProgram/issues/4) · [天体系统 #53](https://github.com/jxt159753/BlockSpaceProgram/issues/53)

| `orbit_spacing` | 卫星半长轴（km） | 霍曼转移（分钟） |
| --- | ---: | ---: |
| `near`（近） | 220–260 | 15–19 |
| `medium`（中，默认） | 330–390 | 25–31 |
| `far`（远） | 480–600 | 40–54 |

`orbit_shape` 选 `regular`（规整，默认）时偏心率和倾角均为 0。选 `natural`（自然）时，偏心率在 0–0.05、倾角在 0–5° 内抽样，升交点经度和近地点幅角也随机。两种形状的历元均为轨道时钟 0 秒，历元平近点角在 `[0, 2π)` 内抽样。

建档前在 `config/blockspaceprogram-server.toml` 设置 `[star_system]`。整合包可以把同名文件放入 `defaultconfigs/`，作为首次生成配置文件时的模板。单人存档和专用服使用相同的设置。

```toml
[star_system]
orbit_spacing = "medium"
orbit_shape = "regular"
seed = ""
```

种子留空时由世界种子和固定盐值派生。填入带引号的有符号 64 位十进制整数可以覆盖派生种子。存档保存实际种子和全部卫星轨道根数，后续重启和配置变更继续使用这些根数。升级旧存档时保留原 M3 轨道，记为 `medium`、`regular` 和种子 0。半长轴为 360 km，历元平近点角为 0，转移时间约 27.79 分钟。

服务器管理员或单人存档房主可执行 `/bsp_star_system`，查看当前档位、实际种子、卫星根数和转移时间。

## 调用方式

- `OrbitElements.stateAt` 按时间计算位置与速度，`fromState` 从同刻的位置与速度求根数。根数以半通径和偏心率表达轨道大小，并提供半长轴、近点和远点。椭圆、抛物线和双曲线使用同一数据结构。 [JPL 开普勒方程](https://ssd.jpl.nasa.gov/planets/approx_pos.html)
- `OrbitalSystem` 提供天体参数、同刻的天体位置与速度，以及拼接圆锥曲线传播。影响球半径取 `a × (μ卫星 / μ父天体)^(2/5)`。进出影响球时使用同一惯性系中的位置和速度拟合新圆锥曲线。服务端只检查轨道范围可能与某个影响球边界相交的飞船。
- `PlanetFrame.atDimension` 和 `atOrbit` 在同一轨道时刻换算维度位置和天体中心惯性位置。速度按东、上、南的正交基底转换，并计入天体自转。姿态和角速度通过同一基底换轴。天空渲染共用该投影。 [星球尺度 #4](https://github.com/jxt159753/BlockSpaceProgram/issues/4)
- `OrbitalSavedData.get(server)` 提供当前天体系统、权威时刻和飞船记录。交接方可用 `put` 存入飞船，再从 `ship` 读取船体 NBT、船体到惯性系的姿态四元数和惯性系角速度（rad/s）。目标维度成功重建刚体和实体后调用 `remove`。 [无人飞船交接与调试命令](flight.md#无人飞船与轨道交接) · [局部物理区 #34](https://github.com/jxt159753/BlockSpaceProgram/issues/34)
- 客户端登录时收到卫星轨道和初始轨道时刻。时钟在常速时每 20 游戏刻同步一次，加速时每游戏刻同步。客户端在两次同步之间用本地游戏刻和半个往返延迟估算显示时刻，实际机动使用服务端时钟。使用生成的天体系统需要新版客户端。 [地图 #15](https://github.com/jxt159753/BlockSpaceProgram/issues/15)
- 多人地图显示当前天体影响球内的在轨无人飞船，以及玩家在其他天体附近的自有飞船。地面玩家按所在维度判断天体，在轨玩家按实际轨道位置判断。换维度、越过影响球边界或飞船离轨时，服务端更新可见飞船。未开放联机的单人存档显示全部在轨无人飞船。 [多人同步 #23](https://github.com/jxt159753/BlockSpaceProgram/issues/23)

## 时间加速

- 安装 Sable 后，未开放联机的单人存档可以在轨道局部物理区滑行时加速。按 **.** 提高倍率，按 **,** 降低倍率。档位为 1、5、10、50、100、1,000、10,000 和 100,000 倍。动作栏显示当前倍率。`/bsp_warp` 查询倍率，`/bsp_warp stop` 立即恢复常速。这些操作无需开启作弊。
- 加速期间天体和在轨飞船随轨道时钟推进。局部物理区的刚体暂停，飞船和舱外玩家继续显示。恢复常速时刚体从原有姿态、线速度和角速度继续模拟。Minecraft 世界、红石和机器仍按游戏刻运行。
- 飞船准备点火或分级、即将下降到交接高度，或有无人飞船即将满足并入物理区的距离和相对速度条件时，自动恢复 1 倍。专用服和开放联机的存档始终使用 1 倍。重开存档时从 1 倍继续。 [时间加速 #16](https://github.com/jxt159753/BlockSpaceProgram/issues/16)

## 轨道地图与机动

- 按 **M** 打开地图。点击飞船或使用「飞船」按钮切换控制对象。点击天体、按住 **Shift** 点击另一艘飞船，或用「目标」按钮轮换目标。右键拖拽旋转视角，滚轮缩放。
- 自然档的卫星轨道标出穿过母星赤道面的升交点和降交点。
- 点击选中飞船的青色轨道线放置或移动节点。横向拖动右侧三条 Δv 数值可调节顺向、法向和径向外分量。按住 **Shift** 精调，按住 **Ctrl** 加快。顺向沿瞬时速度，法向垂直于轨道面，径向外在轨道面内垂直于顺向。金色虚线显示机动后的一小时预测轨迹。
- 目标面板显示未来一小时内的最近距离、到达倒计时和相对速度。已放节点时从该节点开始搜索。天体距离按中心计算，预测进入卫星影响球时标记为交会。若轨迹与目标表面相交，面板和预览线显示首次表面接触。预测使用与服务端一致的拼接圆锥曲线模型。
- 对同向共面的两条圆轨道，面板显示当前相位角和霍曼出发相位角。「霍曼转移」会把一次出发机动放在下一个窗口。M3 的母星 10 km 圆轨道到卫星轨道，出发 Δv 约为 **208.7 m/s**。此节点用来预览转移段和交会。 [NASA 霍曼转移说明](https://science.nasa.gov/learn/basics-of-space-flight/chapter14-1/)
- 单人存档房主和服务器管理员可提交或取消点火。每艘船可提交一个节点，节点时刻以轨道秒保存。界面用当前级的真空推力、有效供油与船重计算所需燃料和等效点火时长。到达节点时服务端以一次瞬时机动更新根数，并扣除供油组中各油箱的燃料。权限细化依赖飞船所有者记录。 [NASA 火箭方程](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/ideal-rocket-equation/) · [飞船所有者 #42](https://github.com/jxt159753/BlockSpaceProgram/issues/42)

复验 M3 转移时，用 `/bsp_ship orbit <飞船UUID> minecraft:overworld 70000 0 0 0 0 0` 将一艘无人飞船放入母星低轨。打开地图，选这艘船和卫星，再点「霍曼转移」即可查看节点和交会预览。 [无人飞船调试命令](flight.md#调试命令)
