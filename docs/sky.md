# 天空渲染

星球维度从 `ship_flight` 数据包读取零海拔和大气参数，服务器在玩家登录和 `/reload` 时同步参数。天体标识与维度标识一致，母星为 `minecraft:overworld`。本模组自带卫星维度 `blockspaceprogram:moon`，零海拔为 Y=63，表面重力为 1.6 m/s²。将维度的 `sea_level_density` 或 `atmosphere_top` 设为零即可使用真空天空。液体和状态效果仍使用原版雾。整合包可用同 ID 的数据包覆盖卫星地形。 [超平坦卫星示例](flight.md#覆盖卫星地形) · [卫星维度 #17](https://github.com/jxt159753/BlockSpaceProgram/issues/17)

相机经纬度按母星默认周长 377,088 格换算。渲染器使用登录时同步的卫星轨道和共享轨道时钟，计算视方向、视半径和受光相位。新存档的轨道间距和历元平近点角会改变天空中的卫星大小和位置。旧存档沿用 M3 的 360 km 圆轨道和初始相位 0。 [天体与新存档](orbit.md#天体与新存档) · [地表映射 #4](https://github.com/jxt159753/BlockSpaceProgram/issues/4)

太阳光沿惯性系 `+Y`，母星每 1,200 轨道秒自转一圈，卫星的本初子午线跟随母星的方向。天体球面的明暗随入射光方向变化，地面天空颜色和客户端光照随当地太阳高度变化。

卫星表面的暗色月海、亮色高地和带辐射纹的环形山按天体 ID 固定。从母星地面看，卫星升起和落下时会变暗、偏红，下雨时会被遮住。晴夜能看到卫星周围的散射光晕。接近新月时，暗面可见微弱的地照，白天暗面融入天空。

飞到建筑高度上限以上后，可以俯视带昼夜分界的星球。靠近球面时，地表上会显出更多细节。母星的云跟随轨道时钟缓慢飘移。太阳照在海洋上时，从反射方向能看到高光。

在高空和轨道上，有大气的星球边缘在日侧泛蓝，晨昏线附近偏橙，夜侧是暗的。越过大气顶后，地形雾关闭，天空背景变黑，仍能看到下方的大气层。高空和真空中的太阳有光晕。晴夜和轨道上可以看到明暗和色温各异的星点，星空随观察者在惯性系中的朝向转动。

## 天体颜色图

服务端开服后在后台先采样母星，再处理其他天体。采样使用维度生成器的生物群系和噪声参数，按等距圆柱投影取格心，不加载区块。客户端按生物群系的地表类别上色，用类别的水面标记决定哪些格子会产生海面反光。

有可用颜色图时，默认在距球面 50 km 及以下完整显示颜色图，50 至 200 km 平滑过渡到程序化图案，200 km 及以上使用程序化图案。高度由相机到天体中心的距离减去天体半径，轨道局部物理区也采用同一计算。云、大气层、海面反光和近距离细节继续随光照与机位显示。

斜看的地平线和球面边缘一带显示区域的平均色。近处放大的颜色图仍保留清晰的方格。

单生物群系、未加载的维度、禁用颜色图的天体，以及采到超过 256 种生物群系的天体使用程序化图案。玩家登录时会收到可用颜色图的清单，服务器生成或刷新颜色图后会自动更新清单。等待颜色图期间显示程序化图案。连接未提供清单的旧版服务端时，也显示程序化图案。

客户端将收到的生物群系网格保存在 `<游戏目录>/blockspaceprogram/surface_maps/`，缓存上限为 64 MiB，超出时先删除最久未使用的文件。客户端收到清单后，仅请求本地缺失或损坏的网格。从不同服务器收到的相同网格共用同一份缓存。上色时使用当前的生物群系数据。

`<存档目录>/serverconfig/blockspaceprogram-server.toml` 的 `[surface_map]` 下可将 `mother_planet_width` 设为 `512`、`1024` 或 `2048`，默认为 `1024`。图高是图宽的一半。其他天体固定为 512 × 256。

每张图保存在 `<存档目录>/blockspaceprogram/surface_maps/<命名空间>/<路径>.bin`，例如 `blockspaceprogram/surface_maps/minecraft/overworld.bin`。开服时会核对格式、分辨率、采样高度和哈希，并重新采样 64 × 32 个均匀分布的原图格心。校验失败会重新生成。

以下命令需要权限等级 2。

- `/bsp_surface_map regenerate [<维度>]` 在后台强制重采样指定天体的颜色图。省略维度时，重采样所有符合生成条件的天体。修改地形或 `sample_y` 后，可以用这条命令刷新。
- `/bsp_surface_map cell <x> <z>` 返回执行者所在维度的颜色图在该坐标处记录的生物群系 ID。每格的值取自格心的采样高度，格内其他位置和地表高度的生物群系可能不同。

### 生物群系配色

数据映射 `blockspaceprogram:surface_color` 的 `values` 接受生物群系 ID 或以 `#` 开头的标签。每个条目必须提供 `color`，格式为 `#RRGGBB`。`water` 默认是 `false`，设为 `true` 时，该格参与海面反光。`priority` 是整数，默认是 `0`。

同一个生物群系匹配多个条目时，直接写 ID 的条目优先。多个标签都匹配时，`priority` 最大的条目优先。优先级相同的标签和重复的 ID 均取后加载的条目。

| 类别 | 匹配 | 颜色 | 水面 | 优先级 |
| --- | --- | --- | --- | ---: |
| 陆地底色 | `#minecraft:is_overworld` | `#606F40` | 否 | 0 |
| 河流 | `#minecraft:is_river` | `#606F40` | 否 | 10 |
| 浅海 | `#minecraft:is_ocean` | `#15446F` | 是 | 10 |
| 深海 | `#minecraft:is_deep_ocean` | `#0D284F` | 是 | 20 |
| 森林 | `#minecraft:is_forest` | `#344D29` | 否 | 10 |
| 丛林 | `#minecraft:is_jungle` | `#264D24` | 否 | 10 |
| 针叶林 | `#minecraft:is_taiga` | `#2A3B31` | 否 | 10 |
| 稀树草原 | `#minecraft:is_savanna` | `#7F7548` | 否 | 10 |
| 沼泽 | `#c:is_swamp` | `#303F2B` | 否 | 10 |
| 蘑菇岛 | `#c:is_mushroom` | `#746775` | 否 | 10 |
| 沙漠与沙滩 | `#c:is_sandy` | `#AE986F` | 否 | 15 |
| 恶地 | `#c:is_badlands` | `#8C593D` | 否 | 20 |
| 岩石 | `#c:is_stony_shores`、`minecraft:stony_peaks` | `#726F6A` | 否 | 20 |
| 雪与冰 | `#c:is_snowy`、`#c:is_icy`、`#c:is_aquatic_icy` | `#B8C6D2` | 否 | 30 |

海冰归入雪与冰。河流使用陆地底色，沙滩使用沙地色，两者都保留采样得到的格子。未匹配的海洋和河流沿用生物群系水色并标记为水面。其他未匹配的生物群系按是否下雪选择雪白或草色。

整合包可以在数据包中添加 `data/blockspaceprogram/data_maps/worldgen/biome/surface_color.json`。以下示例会把浅海改为红色，并给沙漠指定单独的颜色。

```json
{
  "values": {
    "#minecraft:is_ocean": { "color": "#FF0000", "water": true, "priority": 10 },
    "minecraft:desert": { "color": "#D020F0", "priority": -100 }
  }
}
```

在 `values` 同级加入 `"replace": true` 可以整体替换先前数据包的配色。执行 `/reload` 后，在线客户端用已接收的生物群系网格重新上色。

## 天体外观参数

可在 `data/<命名空间>/ship_flight/<维度路径>.json` 中添加 `appearance` 对象。所有字段均可省略。超出范围的颜色、负强度或 `blend_start` 大于等于 `blend_end` 时，服务端记录错误，该天体采用整套默认外观。飞行参数照常加载。

| 字段 | 缺省值 | 含义 |
| --- | --- | --- |
| `surface_map.enabled` | `true` | 是否生成和显示颜色图。 |
| `surface_map.sample_y` | `256` | 采样使用的方块高度，取整数。 |
| `surface_map.blend_start` | `50000` | 完整显示颜色图的最高高度，单位为米。 |
| `surface_map.blend_end` | `200000` | 完整显示程序化图案的起始高度，单位为米。 |
| `moon_surface.highland_color` | `[0.97, 0.96, 0.944]` | 无大气天体的程序化高地颜色。 |
| `moon_surface.mare_color` | `[0.56, 0.546, 0.524]` | 无大气天体的程序化月海颜色。 |
| `atmosphere.extinction` | `[0.047, 0.085, 0.145]` | 从该天体内部看天空时的晴天消光系数。 |
| `atmosphere.halo` | `0.058` | 从该天体内部看天空时的卫星散射光晕强度。 |
| `atmosphere.limb_day_color` | `[0.15, 0.46, 0.86]` | 从高空或太空看球面时，日侧大气层的颜色。 |
| `atmosphere.limb_twilight_color` | `[0.86, 0.34, 0.11]` | 从高空或太空看球面时，晨昏线附近大气层的颜色。 |
| `cloud_opacity` | `0.90` | 云层最大不透明度，范围为 0 至 1。设为 0 可隐藏云层。 |
| `water_glint_strength` | `1` | 海面反光的强度倍率。 |
| `surface_detail_strength` | `1` | 近距离高频地表细节的强度倍率。 |

颜色使用 `[r, g, b]` 数组，每个通道的范围为 0 至 1。执行 `/reload` 后，客户端立即应用外观参数。改变采样高度或为尚无颜色图的天体启用采样后，执行 `/bsp_surface_map regenerate` 或重启服务器生成颜色图。地面的蓝天渐变和日落沿用天空渲染的原有配色。

## Iris 光影

启用 Iris 光影包时，光影包继续绘制地形和阴影，模组在场景合成后绘制天空、卫星相位和星球球面。光影包自己的云和天空特效可能被模组天空覆盖。

光影包读取的本地昼夜时间会随轨道时钟变化。光影包的太阳轨迹使用固定的倾角，高纬度的地面阴影可能与模组中太阳的方位有偏差。

卫星维度使用黑色天空。光影包可为地形额外绘制大气雾。Complementary Reimagined 和 BSL 的卫星维度映射及去雾设置见整合包说明。 [整合包光影配置](https://github.com/jxt159753/BlockSpaceProgram-Modpack/blob/main/README.md#iris-光影) · [天空光影兼容 #52](https://github.com/jxt159753/BlockSpaceProgram/issues/52)

## 轨道空间

进入轨道局部物理区后，天空使用参考轨道与相机在区内的偏移。星球随飞船在轨道上的位置改变。物理区重定基准时，服务端同步新的参考轨道。维度内的 `(x, y, z)` 偏移映射到惯性系的 `(x, -z, y)`，两边单位均为米。 [轨道局部物理区](flight.md#轨道局部物理区) · [局部物理区 #34](https://github.com/jxt159753/BlockSpaceProgram/issues/34)
