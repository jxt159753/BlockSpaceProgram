# 烘焙与拆解零件

1. 用一个工作台、一枚铁锭和一枚铜锭合成烘焙台，摆在开阔处。
2. 在台面正上方放置第一块方块，再通过方块的面相接搭出模块。扫描区域从台面上方一格起，水平东西与南北各延伸四格，向上共九格。区域内的方块须连成一体，模块与区域外的方块之间须留出空隙，烘焙台本身除外。
3. 手持铜锭右击烘焙台。烘焙成功后，原方块移除并扣除一枚铜锭。悬停零件可查看干质量和各类燃料容量。
4. 手持烘焙零件右击烘焙台拆解。零件会被消耗，返还的方块物品来自该零件保存的结构。门或床的两个部分合计返还一个物品。

扫描使用干燥、可破坏且有对应方块物品的方块。搭建模块时避开带方块实体的方块，例如容器和告示牌。

## 燃料舱示例

将空炼药锅放在台上，旁边接一个铁块，再在铁块上方放一个空炼药锅。烘焙后应得到干质量 **300 kg**、液体燃料容量 **200 kg** 的零件，拆解返还两个空炼药锅和一个铁块。可通过[零件属性数据包](part-properties.md)配置其他燃料和材料。

## 零件数据

`blockspaceprogram:part_data` 保存原方块状态和相对于结构最小角的坐标，以及类型、汇总属性、质心和关于质心的惯量张量。质量、各燃料容量、推力、阻力贡献和电量相加。两类比冲各取产生推力的方块按推力加权的调和平均，所需比冲缺失时该项为零。耐热取已配置的最小正值。每个方块按质量均布的单位立方体计算，零总质量结构以所有方块中心的均值为质心。
